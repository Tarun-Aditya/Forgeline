Lumen Books API

Base URL http://127.0.0.1:4010. Send Authorization: Bearer lumen-demo-token on every call. Errors are JSON: {"code": "...", "message": "..."}.

This page is the only description of the API here: there is no OpenAPI file for this variant. It is what the GraphOS "no spec, docs only" start uses, so an agent has to discover the shapes by reading this and probing the live service.

Books

GET /books

Lists books, 10 per page by default. Query: page (from 1), limit (max 50), genre. Returns {"data": [Book], "meta": {"page": 1, "limit": 10, "total": 10}}.

GET /books/{id}

One book. 404 if the id is unknown.

{"id": "b1", "title": "The Salt Archive", "authorId": "a1", "priceCents": 1899,
 "currency": "USD", "genres": ["scifi"], "publishedAt": "2019-03-04", "stock": 14}

authorId refers to GET /authors/{id}.

Authors

GET /authors/{id}

One author: id, name, optional bio, optional born.

Orders

GET /orders

Lists orders. Query: customerId, status (pending, paid, shipped, cancelled), after (cursor), limit. Returns {"data": [Order], "nextCursor": "o2" | null}.

GET /orders/{id}

One order. customerId refers to GET /customers/{id}.

POST /orders

Body: {"customerId": "c1", "items": [{"bookId": "b1", "quantity": 1}]}. Returns 201 and the order. 422 when the customer or a book is unknown.
